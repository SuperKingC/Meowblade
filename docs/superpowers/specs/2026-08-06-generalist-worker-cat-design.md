# 通用工人猫视觉设计

## 目标

为《喵剑奇箱》生成一张通用工人猫概念立绘。角色不绑定纸箱回收、小鱼干厨房或奇箱拆解中的任何单一岗位，可以作为三个生产岗位共享的基础角色，并通过后续替换头饰、手持物和腰部挂件形成岗位变体。

## 角色设计

- 角色是一只橘白相间的拟人猫，三头半身比例，体型结实但不过分壮。
- 面部友善、可靠、略带认真开工的神情，避免英雄式威严或明显疲惫。
- 穿低饱和青绿色背带工装裤、奶油色卷袖上衣和芥末黄小方巾。
- 工装保留简洁的空挂点，方便后续添加纸箱手套、厨房围裙或拆解工具。
- 不使用岗位专属帽子、围裙、工具、资源或徽记。
- 动作为站立全身姿势：一只手正在拉紧另一只手的工作手套，表现“准备开工”，同时保持双手附近轮廓清楚，便于后续替换道具。

## 视觉语言

- 延续 `art_master_heroes_lineup_v01.png` 的温暖手绘玩具感。
- 使用柔和的绘本笔触与轻度立体渲染，毛发细节适中，不追求写实毛发。
- 材质重点是旧棉布、帆布工装、轻微缝补和柔软猫毛；避免复杂金属与现代塑料质感。
- 色彩以奶油白、低饱和橙、青绿色和芥末黄为主，与现有纸箱棕、毛线紫等项目色彩兼容。
- 背景为干净温暖的米白色，只保留柔和落地阴影，不加入生产站或环境叙事。

## 构图与输出

- 单角色、全身、正面略带三分之四角度，居中构图。
- 耳朵、尾巴、双手和双脚完整出现在画面中，四周保留充足留白。
- 概念稿使用横向画布，视觉比例与现有角色母图一致。
- 最终文件保存为 `Assets/Art/Concept/VisualDirection/art_concept_worker_generalist_v01.png`。
- 本次交付是概念立绘，不是透明背景 Sprite，也不直接作为 Spine 分层源文件。

## 生成约束

- 输入图片 `art_master_heroes_lineup_v01.png` 仅作为风格、材质、比例和光照参考，不是编辑目标。
- 只生成一只猫，不加入其他角色。
- 不加入纸箱、鱼干、齿轮、扳手、厨具、办公用品或其他职业专属道具。
- 不出现文字、Logo、水印、界面元素、现代电子设备或品牌标记。
- 避免多余肢体、遮挡的手、裁切耳朵或尾巴，以及服装结构不连贯。

## 验收标准

1. 第一眼能识别为正在准备工作的通用工人猫，但无法仅凭服装判断具体岗位。
2. 角色风格、比例、光照和材质与现有三主将母图协调。
3. 角色全身及尾巴完整，轮廓清楚，手套动作自然。
4. 青绿色工装、奶油色上衣、芥末黄方巾和橘白毛色关系清晰。
5. 画面中没有岗位专属道具、文字、Logo 或水印。
6. 文件写入约定的项目路径，可作为后续岗位变体的视觉基准。
