# 视觉方向概念资源

这批图片用于确认《喵剑奇箱》Demo 的统一美术语言，不是最终可拆分的角色精灵、图集或 UI Prefab 素材。

## 统一方向

温暖手绘纸箱幻想 + 夸张猫猫喜剧 + 轻军团玩具感 + 清晰的移动游戏轮廓。

核心材质：瓦楞纸板、封箱胶带、旧木材、陶瓷碗、毛毡、毛线、拉丝齿轮。

核心色彩：纸箱棕、奶油白、低饱和橙、青绿色金属、毛线紫、深梅色阴影。

## 生成记录

生成方式：OpenAI 内置 `image_gen`，每个独立资产单独调用。

统一约束：无 Logo、无水印、无现代电子设备；避免依赖图片中的可读文字，UI 文字由 Unity 的本地字体和代码动态渲染。

尺寸由生成服务返回，当前版本为：

- 主界面：1672 x 941 PNG
- 三主将：1672 x 941 PNG
- 战斗场景：1672 x 941 PNG
- UI 风格板：1536 x 1024 PNG

## 后续制作建议

1. 先从主界面和战斗场景中拆出背景层、平台层、装饰层，作为临时 Parallax 背景。
2. 依据角色设定图分别重绘或生成透明背景角色 Sprite，再制作待机、移动、攻击、受击四组动画。
3. 按 UI 风格板重新制作可拉伸的九宫格底板、图标、进度条和按钮，不要直接把整张风格板放进运行时 UI。
4. 最终入库前统一检查 Sprite 导入设置、Pixels Per Unit、压缩格式、移动端最大纹理尺寸和图集分组。

## 第二批 Demo 派生资源

第二批资源由 `Tools/Art/process_concept_assets.py` 从已确认的四张概念母图派生，输出到 `Assets/Resources/Art/`，不改变原始概念图：

- `Backgrounds/`：猫宅生产背景、原始战斗巷道背景，以及为动态单位降细节处理的 `battle_alley_temp_v02` 战术背景；
- `Characters/`：纸箱侠、小鱼干、毛线球的临时透明战斗立绘；
- `Portraits/`：三名主将头像、三支小猫军团头像、纸箱鼠头像、胶带鼠队长头像；
- `Stations/`：纸板、鱼干、零件三个生产站缩略图；
- `UI/Resources/`：纸板、鱼干、奇箱零件三种资源图标。

当前共 20 张运行时 PNG。这些文件带有“`temp`”、“`v01`”或“`v02`”标记，表示可以用于当前 Demo 的运行时视觉验证，但不替代最终 Spine 分层、独立动画帧和正式图集。角色自动抠图保留了窄的奶油色纸边，这个边缘是为了保证在深色战斗背景上的可读性；正式生产时应由原画统一描边规则。`battle_alley_temp_v02` 对自带角色的概念背景做了模糊和降对比处理，让运行时单位成为清晰前景，正式阶段仍应替换为不带静态角色的分层场景。

派生资源总览：`Assets/Art/Production/Preview/production_asset_sheet_v01.png`。
