# 《喵剑奇箱》美术资源清单与 AI 生产规划

## 1. 推荐视觉方向

当前玩法最适合“温暖手绘纸箱幻想 × 夸张猫猫喜剧 × 轻军团玩具感”的 2D 风格。

建议特征：

- 三头身到四头身猫猫，轮廓清楚，表情夸张；
- 纸板、胶带、鱼干、毛线、齿轮形成统一材料语言；
- 猫宅使用暖棕、奶油黄、橙色灯光；
- 战斗使用更高对比度，技能色彩明显；
- UI 像纸箱标签、胶带贴纸和猫爪印；
- 避免写实毛发和复杂金属，以控制动画和移动端性能成本。

正式生产前应先锁定一张猫宅风格稿、一张战斗风格稿和三主将同框设定。没有锁定这三项之前，不建议直接批量生产角色动画。

## 2. 首个可对外试玩版本需要的资源

### 2.1 视觉规范

| 资源 | 数量 | 规格 | 优先级 |
|---|---:|---|---|
| 总体风格板 | 2～3 张 | 角色、场景、材质、色彩、光照参考 | P0 |
| 色板 | 1 套 | 猫宅、普通战、Boss、品质色 | P0 |
| 线条与阴影规范 | 1 套 | 描边粗细、阴影层级、发光规则 | P0 |
| 尺寸比例表 | 1 张 | 主将、小猫、工人、鼠、Boss 对比 | P0 |
| UI 视觉规范 | 1 套 | 字体、字号、圆角、描边、按钮状态 | P0 |

### 2.2 三名主将

主将：纸箱侠、小鱼干、毛线球。

每名主将建议准备：

- 正面/侧面/背面角色设定；
- 战斗全身原画；
- 头像和编队卡头像；
- 5 个基础表情：普通、开心、生气、受伤、胜利；
- 武器、披风或核心道具拆分；
- 待机、移动、普攻、技能、受伤、撤退、胜利动作；
- 对应技能图标；
- 主界面展示版本。

推荐采用 Spine 骨骼动画：

- 单角色源文件画布：`2048×2048`；
- 分层内容：头、耳、眼、嘴、身体、四肢、尾巴、武器、披风、前后装饰；
- 图集：优先 `2048×2048`；
- 基础动画：Idle、Move、Attack、Skill、Hit、Retreat、Victory；
- 纸箱侠额外：Taunt、Shield、CapeIdle；
- 小鱼干额外：Throw、DoubleThrow、Execute；
- 毛线球额外：Cast、YarnArea、SlowLoop。

### 2.3 小猫军团

至少需要三种军团视觉：

- 纸箱侠小队：小纸盾、纸板头盔；
- 小鱼干小队：鱼骨投手、轻装；
- 毛线球小队：毛线法杖、绒球帽。

每种至少包含：

- 1 个基础造型；
- 2～3 个颜色或配件变体；
- Idle、Move、Attack、Hit、InjuredRetreat；
- 受伤状态头像；
- 空缺、可用、受伤三种编制图标。

如果控制成本，可以让同军团的小猫共享骨骼，仅替换颜色和少量挂件。

### 2.4 工人猫

Demo 中有三只工人猫，建议使用同一基础骨骼加三种外观。

通用动作：

- Idle；
- Walk；
- Carry；
- Rest；
- ChangeJob；
- StorageFull；
- Celebrate。

岗位动作：

| 岗位 | 动作 |
|---|---|
| 纸箱回收角 | 抓纸箱、撕胶带、压纸板、搬运纸板 |
| 小鱼干厨房 | 推碗、烘鱼干、闻鱼干、偷吃被发现 |
| 奇箱拆解台 | 拨齿轮、追弹簧、拍按钮、搬运零件 |

### 2.5 敌人和 Boss

首批敌人：

- 纸箱鼠；
- 胶带鼠；
- 增援纸箱鼠；
- Boss 纸箱小霸王。

普通敌人至少需要：

- Idle、Move、Attack、Hit、Down；
- 正常头像或图鉴小图；
- 阴影和受击闪白遮罩。

Boss 额外需要：

- 登场；
- 普攻；
- 箱盖重压预警；
- 箱盖重压落下；
- 半血召唤；
- 狂暴/受伤状态；
- 倒地和胜利结算特写。

### 2.6 猫宅场景

建议制作一张可覆盖 20:9 的横屏场景母版：`3200×1440`。

分层资源：

- 远景墙面与窗户；
- 中景地板与平台；
- 前景纸箱和猫爪装饰；
- 纸箱回收角；
- 小鱼干厨房；
- 奇箱拆解台；
- 三类仓库；
- 猫窝；
- 奇箱工坊；
- 中央休息垫；
- 出战入口；
- 猫宅等级 1/2 外观差异；
- 第四只工人猫剪影预告。

每个生产岗位最好拆成：

- 静态底图；
- 可动画机械部件；
- 资源堆积层；
- 满仓状态；
- 高亮/可点击状态；
- 阴影和前景遮挡层。

### 2.7 战斗场景

首批需要两套：

1. 普通关：夜晚后巷或纸箱仓库；
2. Boss 关：纸箱王座/大型纸箱内部。

每套建议包含：

- `3200×1440` 背景母版；
- 远、中、近三层视差背景；
- 地面战斗带；
- 前景遮挡；
- 入场点和敌方出生点；
- 普通光照版和技能压暗版；
- 可循环的小环境动画，如灯闪、纸屑、尘埃。

### 2.8 UI 资源

首批 UI 至少需要：

- 顶部资源条；
- 资源图标：纸板、鱼干、奇箱零件；
- 工人分配按钮和计数器；
- 岗位卡和进度条；
- 猫窝、工坊、出战按钮；
- 主将卡和小猫编制状态；
- 3×2 编队格；
- 血条、护盾条、Boss 血条；
- 号令按钮和能量条；
- 速度按钮、撤退按钮；
- 胜利/失败弹窗；
- 普通、按下、禁用、选中四种按钮状态；
- 9-Slice 面板和弹窗底框；
- Toast、提示气泡、红色预警条；
- 猫爪光标或点击反馈。

建议 UI 图标母版为 `512×512`，最终根据使用位置输出 128、256 或 512 尺寸。面板和按钮必须提供 9-Slice 安全边界说明。

### 2.9 技能与环境特效

首批至少需要：

- 普通命中；
- 暴击命中；
- 纸板碎屑；
- 鱼骨飞行和命中；
- 毛线范围圈和减速缠绕；
- 纸箱侠护盾；
- 嘲讽标记；
- 箱盖重压红色预警；
- 箱盖落下冲击；
- 全军钻箱；
- 小猫受伤撤退；
- 胜利撒纸屑；
- 猫宅升级光效；
- 资源生产和入仓反馈。

特效纹理建议使用 256、512、1024 三档，避免所有特效都使用大尺寸贴图。

### 2.10 音频资源

虽然不属于纯美术，但对试玩质感影响很大：

- 猫宅 BGM 1 首；
- 普通战 BGM 1 首；
- Boss 战 BGM 1 首；
- UI 点击、确认、禁用、弹窗音效；
- 三种资源生产和入仓音效；
- 三名主将普攻与技能音效；
- 敌人受击和倒地音效；
- Boss 预警、重压、召唤音效；
- 号令、胜利、失败、猫宅升级音效；
- 适量猫叫和喜剧拟声音效。

首个对外试玩版本建议准备约 25～35 个短音效。

## 3. 首批美术生产包建议

不要一开始就生产全部动画。建议按以下四张核心图锁定方向：

1. 猫宅主界面风格稿，16:9，包含三个生产岗位和三只工人猫；
2. 普通关战斗风格稿，包含三主将、小猫军团和纸箱鼠；
3. 纸箱侠、小鱼干、毛线球三主将角色设定同框；
4. UI 风格页，包含顶部资源条、岗位卡、按钮、弹窗和号令按钮。

这四张确认后，再生产：

- 三主将分层原画；
- 工人猫与小猫军团；
- 敌人与 Boss；
- 猫宅分层场景；
- 战斗场景；
- UI 切图；
- Spine 动画和特效。

## 4. 我可以直接生产的内容

我可以使用图像生成能力直接帮助生产：

- 视觉风格探索图；
- 猫宅和战斗场景概念图；
- 三主将角色设定方案；
- 工人猫、军团小猫和敌人造型方案；
- 角色头像、立绘和透明背景展示图；
- UI Style Frame 和界面氛围稿；
- 资源、技能、建筑和功能图标初稿；
- 纸板、胶带、毛线、鱼干等材质贴图；
- 部分发光、烟尘、纸屑和冲击纹理；
- 商店宣传图、启动图和 Key Art 草案。

适合直接作为占位或经过简单整理后进入 Unity 的内容：

- 背景图；
- 头像和卡面；
- 图标初稿；
- 静态装饰；
- UI 视觉参考；
- 特效基础纹理。

## 5. 需要人工或专业工具收尾的内容

图像生成不能自动替代完整美术生产管线。以下内容仍需要人工整理或专门软件：

- 保持所有角色在不同动作和角度下完全一致；
- 按 Spine 规范拆分头、四肢、武器、前后遮挡层；
- 骨骼绑定、权重、网格和动画曲线；
- 可无缝循环的高质量逐帧动画；
- 9-Slice 边界、图集和像素级 UI 对齐；
- PSD/PSB 分层命名和最终清线；
- SpriteAtlas、压缩格式、Pivot 和 PPU 设置；
- 字体授权和嵌入；
- 真机颜色、内存、Overdraw 和批次优化；
- 音乐、音效和语音资源。

比较现实的协作方式是：我先生成风格稿、角色方案、背景和图标初稿，再由美术进行统一清线、分层、绑定和引擎适配。这样能够明显减少概念探索和草稿成本，同时保持最终资产的稳定一致性。

## 6. 推荐文件与导入规范

```text
Assets/Art/
├─ Characters/
│  ├─ Heroes/
│  ├─ Kittens/
│  ├─ Workers/
│  └─ Enemies/
├─ Environments/
│  ├─ Home/
│  └─ Battle/
├─ UI/
│  ├─ Common/
│  ├─ Home/
│  ├─ Formation/
│  └─ Battle/
├─ VFX/
├─ Animations/
├─ Materials/
└─ Atlases/
```

命名建议：

- `chr_hero_cardboard_knight_body`
- `chr_worker_cardboard_idle`
- `env_home_station_fish_level01`
- `ui_icon_resource_cardboard`
- `vfx_boss_slam_warning`
- `atlas_characters_heroes`

Unity 导入建议：

- 普通 2D 图使用 Sprite；
- UI 面板关闭 Mipmap；
- 场景背景根据缩放需求决定 Mipmap；
- 透明图使用合适的 Alpha 设置；
- 同界面资源进入同一 SpriteAtlas；
- Android 优先 ASTC，低端兼容 ETC2；
- 不要在 Assets 内长期保留大量未压缩、未使用的概念稿。

## 7. 当前建议

下一批最有价值的 AI 美术交付不是零散图标，而是先生成：

1. 猫宅主界面最终风格候选 2 版；
2. 三主将角色同框设定 2 版；
3. 普通关战斗场景 1 版；
4. UI 视觉规范页 1 版。

确认其中一套后，再沿同一风格批量生产角色、场景和图标，能最大限度保证一致性。
